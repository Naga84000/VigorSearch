# VigorSearch

傀異錬金術・覇気のスキル抽選の結果を初期 State から一覧表示・検索する Windows アプリです。
観測したスキル名から初期 State を復元する機能もあります。

## 注意事項

- このツールのコードはClaudeを利用して作成しています。
- 自己完結のためファイルサイズは大きめ(約150MB)です。
- 実機で動作確認済みですが検索結果が全て正しいと保証することはできません。
- 不具合を見つけた場合、Issues で教えてください。

## 動作環境

- Windows

## 機能

- **一覧表示**: 初期 State(S0〜S3、16進)と開始位置・件数を指定して、スキル1/スキル2、各レベル、スロットを一覧にします。
- **検索**: スキル1/スキル2、希望レベル(Lv ≧ n)、スロットで条件を指定して探します。スキル1/2は順不同でも検索できます。探索範囲と最大ヒット数も指定でき、途中で中止できます。
- **State の復元**: 観測したスキル名を書いたテキストファイルから初期 State を復元します。

## 使い方

1. 初期 State の S0〜S3 を16進で入力します。
2. 「一覧表示」で指定した開始位置から結果を表示します。
3. 一覧の State 列をダブルクリックするとその行の開始 State が初期 State に設定されます。
4. 検索する場合は条件を指定して「検索」を押します。

### State の復元

連続した第一スキルの情報から復元を行います。
観測ファイル(既定は `obs.txt`)に観測したAランクのスキル名を1行に1つずつ書きます。
添付された `obs.txt`には既に観測記録が書いてありますが、ただのサンプルなので消してください。
Aランク以外のスキルが出た場合、その行(復元に使わない行)にはスキル名以外の文字を入れておきます。行番号は数えられるので行を詰めないでください。

「Stateを復元」を押すと exe と同じフォルダ(なければカレントフォルダ)のファイルを読み、成功すれば S0〜S3 の欄に値が入ります。
観測が少ないと復元できません。その場合は不足しているビット数が表示されます。

## 備考

- 抽選ロジックと各種テーブルは`Core/Generator.cs` と `Core/SkillData.cs` にあります。
- 1回の抽選で乱数は9回進みます。
